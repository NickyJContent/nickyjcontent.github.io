Privacy Policy

Last updated: October 18, 2026

This policy covers this website and Channel Manager, a private desktop tool that the owner of NickyJ Content uses to upload videos to the owner's own YouTube channels. Channel Manager is not offered to the public.

What Channel Manager accesses

Channel Manager uses the YouTube API Services. With the channel owner's permission it requests two Google permissions: uploading videos to the signed-in YouTube channel, and reading basic information about that channel (its name and ID) so it can confirm it is posting to the right one.

How that information is used and stored

The sign-in token and channel name and ID are stored only on the owner's own computer. They are used solely to upload the owner's videos and set their titles, descriptions, thumbnails and publish times. No data is sold, shared with third parties, or used for advertising, and nothing is sent to any server other than Google's.

This website

This site is a static page hosted by GitHub Pages. It sets no cookies and runs no analytics. GitHub may log standard technical information such as IP addresses; see the GitHub Privacy Statement.

Google and YouTube

By using YouTube you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Revoking access

Access granted to Channel Manager can be removed at any time from the Google Account connections page. Deleting the app's local token file also ends its access.

Contact

Questions about this policy can be sent through the Far Window Sounds channel page.
